DXVK — не застосовано

DXVK перенаправляє Direct3D 9 через Vulkan для кращої сумісності і продуктивності.

Розташування DLL C:\Windows\SysWOW64\d9vk.dll
Лаунчер відновить оригінальний d3d9.dll з exe_backup/d3d9.dll_dpfix_only і видалить системний DLL.

Скинути все

Видаляє збережені налаштування і журнал подій лаунчера. Лаунчер перезапуститься й покаже першозапуск. Файли гри й резервні копії сейвів не чіпаємо.

      Про режими сумісності

      Ці налаштування допомагають запустити гру на старих та сучасних системах Windows. Використовуйте рекомендовані параметри для найкращої сумісності.

      Фікси для DPC
      Пропустити заставки

      Патчить байт 0x243333 у .exe щоб пропустити логотипи. Працює коли ставиться ОСТАННІМ — після 4GB Patch + DPfix.

      FPS-cap 60 —

      Гра ламається на FPS > 60. Налаштуй ліміт у панелі GPU.

      Звук: handbrake/двигун зациклюється? 5.1 / 7.1 → Stereo

      На системах із surround 5.1/7.1 деякі звуки гри (особливо ручник машини й двигун) можуть зациклюватись і бути занадто гучними. Це обмеження аудіо-движка DP. Швидкий фікс: переключити Windows на 2 канали (стерео) на час гри.

      Якщо переключити не вийшло (наприклад, 7.1-навушники Logitech G35): підключіть звичайні стерео-навушники, зробіть їх default-пристроєм, далі Recording → ввімкніть Stereo Mix та зробіть його default; у властивостях Stereo Mix → «Listen to this device» → виберіть свої справжні колонки.

      Use DXVK (Vulkan wrapper)

      DXVK перетворює D3D9 у Vulkan — допомагає на старих драйверах, але на RTX 40/50 + Win11 додає 2-3× до часу завантаження через JIT-компіляцію pipeline-ів. Вимкни для швидкого старту (native D3D9). DPfix-фікси (widescreen, FOV) лишаються активні в обох випадках.

      Native codec priority

      Тимчасово знижує merit LAV-фільтрів під час гри. Auto-revert при виході.

      Ховати курсор у грі

      Фоновий watcher ховає курсор поки гра у фокусі.

      DPfix: capture cursor

      Альтернатива до PS-watcher'а. Захоплює курсор у вікні гри через DPfix (D3D9-рівень).

      Стабільність

      Інструменти для підвищення стабільності, діагностики та сумісності гри на сучасних системах.

      Recommended Stability Mode

      Композитний режим для крашів навколо катсцен / loading / building transitions та для безпеки сейвів. Це НЕ audio-pool патч — він спрямований на класи багів, які community report'ить найчастіше (transition state, cutscene boundaries, codec/PhysX runtime).

      Стан режиму Не застосовано
      Crash dumps FPS cap 60 DPFix borderless

      Параметри стабільності

      Crash Dump Helper —

      Налаштовує Windows Error Reporting LocalDumps для DP.exe у HKCU (без адмін-прав). Дампи зберігатимуться у %LOCALAPPDATA%\CrashDumps\.

      Media / Cutscene Compatibility —

      Шукає codec packs (LAV, K-Lite, MPC-HC, Shark007, ffdshow), які можуть викликати фріз/чорний екран на катсценах WMV. Тільки detection, нічого не змінює автоматично.

      Legacy PhysX Check —

      Перевіряє наявність NVIDIA PhysX legacy runtime який DP1 використовує для фізики. Steam Deck reference setup юзає PhysX 9.13.0725.

      Controller Compatibility (Xidi) —

      Xidi — обгортка над старим DirectInput для сумісності з XInput-контролерами (Xbox/PlayStation/Steam Deck). Тільки якщо є проблеми з контролером — це не crash fix, не для більшості users.

      GPU Driver Compatibility —

      Старі AMD/Intel D3D9 драйвери можуть deadlock'ати на certain game scenes (підтверджено dump-аналізом Ch.3 hospital hang). Якщо у тебе random hangs не на завантаженні, а посеред gameplay — DXVK ймовірно це виправить.

      ⚠ Experimental: NaN Hang Guard —

      Experimental. Modifies DP.exe on disk (2 bytes, with backup). Replaces an internal infinite-loop assert at VA 0x00409EA6 with two NOPs so NaN float input returns 0.0f instead of hanging the thread. Pattern-scanned and SHA-256-verified — refuses if your DP.exe doesn't match. Use only if you experience random AppHang freezes during Ch.3 / loading transitions.

      Пресети рендеру
      
                
      
                  Переключайтесь між готовими конфігураціями рендеру. Усі пресети зберігають
                  DPfix hex-патчі у DP.exe (widescreen / FOV / 4GB) — змінюється лише
                  як DP.exe ходить у D3D9 через DXVK (Vulkan), через native D3D9, або обидва.
                
      
              
      
              
                
                  
                
                
                  Детальніше про пресети
                  Який пресет обрати?
                
                
              
            
      

            
            
      
              
              
      
                Чому DPfix-only — за замовчуванням?
                
                  На сучасних NVIDIA з FPS-cap у драйвері DXVK може давати
                  лоадинги по 5-10 хв (DP прив'язує таймінг до кадрів).
                  Якщо ти не маєш проблем із native d3d9 — лиши «Тільки DPfix».
                  DXVK-пресети — для випадків, коли потрібен Vulkan-рендер.
                
              
      
            
      

            
      
              

              

              

              
            
      

            
      
              
              
              
                
                Поточний: 
                —
              
            
      
            
      

            
      
              
      
                
                
      
                  
      Як працюють пресети?
      
                  
      Пресети змінюють спосіб рендеру гри та роботу DPfix. Ви завжди можете повернутися до стандартних налаштувань або спробувати інший пресет.
      
                
      
              
      
              
      
                
                
      
                  
      Зміна пресету може вплинути на продуктивність та сумісність. Рекомендуємо протестувати різні варіанти.
      
                
      
              
      
            
      
          
      

          
          
      
            
      Shader Cache
      
            
      
              DXVK 2.x на сучасних драйверах делегує кеш шейдерів драйверу
              (NVIDIA DXCache / AMD DxCache). Stutter першого проходу — нормальна
              JIT-компіляція; з кешем наступні рази плавно. Файл dp.dxvk-cache
              у директорії гри не обов'язковий.
            
      
            
      
            
      
              
              
            
      
            
      
          
      

          
          
      
            
      
              Автоматичне резервне копіювання dp.sav
              кожні 2 хвилини захищає ваш прогрес у разі вильоту гри.
